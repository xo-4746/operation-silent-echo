# 🛡️ Operation Silent Echo — DFIR Challenge

At 08:42, security monitoring at **Apex Dynamics** flagged unusual DNS traffic
from a finance department workstation. Evidence suggests unauthorized data access,
suspicious browser activity, and outbound communications inconsistent with
normal business operations. The SOC has escalated the event to you — the
Digital Forensics and Incident Response team.

**Your mission:** reconstruct the attack timeline, identify the attacker's
methods, determine the scope of compromise, and recover all **six flags**
before it's too late.

## ▶️ How to play

Open the challenge here:

👉 **https://xo-4746.github.io/operation-silent-echo/**

- **Tools allowed:** only your browser — View Source (Ctrl+U), DevTools (F12),
  and your wits. No external tools, no scripts, no hint sites.
- **Flags look like:** `flag{...}` — submit each one in its case card.
- **Requirements:** a laptop/desktop with Chrome, Edge, or Firefox.
  (Phones won't cut it — you need DevTools.)
- **Difficulty:** intermediate · **Time:** 45–90 minutes
- **Progress saves automatically** in your browser.

## 🎯 What you'll practice

Real digital-forensics techniques, played out in the browser:

1. Reading source code like an investigator
2. Spotting anomalies in application audit logs
3. Inspecting browser storage (cookies / localStorage) for tampered sessions
4. Digging into file and image metadata
5. Detecting DNS-tunneling exfiltration
6. Classic cipher work — because attackers still use them

## 📜 Rules

- Play fair: solve it yourself. Sharing answers ruins the exercise.
- Everything is simulated. **No real systems, no real data, no real attacker.**
- Mentor/answer key is distributed separately — don't ask. 😉
